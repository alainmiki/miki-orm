# Plan: Django-like Project Structure and CLI App Creation

## Overview
Implement a Django-inspired project structure for miki-orm with:
1. A standardized `settings.py` configuration pattern
2. CLI command `startproject` to create new projects
3. CLI command `startapp` to create new apps with boilerplate code

## Command Behavior (Updated per requirements)

### `startapp` Command Variants
- `miki-orm startapp users` - Creates `users/models.py` and `users/app.py` in current directory (flat structure)
- `miki-orm startapp users myapp` - Creates `myapp/users/models.py` and `myapp/users/app.py` (nested in folder)

### `startproject` Command Variants  
- `miki-orm startproject conf .` - Creates project in **current directory** with settings in `conf/settings.py`
- `miki-orm startproject conf myproject` - Creates project in `myproject/` directory with `myproject/conf/settings.py`

## Current State Analysis

### Existing Components
- **`mikiorm/conf/settings.py`**: Already has `Settings`, `DatabaseConfig`, and `configure()` function
- **`mikiorm/models/register.py`**: Has `AppRegistry`, `AppConfig`, and `@register` decorator for app-based model registration
- **`mikiorm/cli/cli.py`**: Unified CLI with commands for migrations, database operations

### Missing Components
- No `INSTALLED_APPS` concept in settings
- No `startproject` CLI command
- No `startapp` CLI command
- No standardized project template structure

## Proposed Implementation

### 1. Enhanced Settings Structure

Add `INSTALLED_APPS` support to the `Settings` class:

```python
# New in mikiorm/conf/settings.py
class Settings:
    def __init__(self):
        self.INSTALLED_APPS = []  # List of app module paths
        self.DATABASES = {}     # Django-style database config
        # ... existing fields

    def configure_apps(self, app_modules: List[str]) -> None:
        """Configure installed apps by importing and registering them."""
        for app_module in app_modules:
            try:
                module = importlib.import_module(app_module)
                if hasattr(module, 'default_app_config'):
                    # Use AppConfig from module
                    app_config = module.default_app_config
                # Auto-discover models in the app
            except ImportError:
                logger.warning(f"Could not import app: {app_module}")
```

### 3. CLI Commands to Add

#### `startproject` Command
Usage: `miki-orm startproject myproject`

Creates:
- Project directory structure
- `settings.py` with template configuration
- `manage.py` entry point

#### `startapp` Command  
Usage: `miki-orm startapp users`

Creates:
- `apps/users/__init__.py`
- `apps/users/app.py` with `AppConfig` class
- `apps/users/models.py` with base imports

### 4. Boilerplate Code Templates

#### `settings.py` Template
```python
"""Miki-ORM project settings."""
from mikiorm.conf import configure

# Database configuration
DATABASES = {
    "default": {
        "ENGINE": "sqlite",
        "NAME": "db.sqlite3",
    }
}

# Installed applications
INSTALLED_APPS = [
    "apps.users",
]

# Initialize ORM
configure(
    databases=DATABASES,
    model_paths=["apps"],
)
```

#### `app.py` Template (AppConfig)
```python
"""App configuration for users app."""
from mikiorm.models.register import AppConfig

class UsersAppConfig(AppConfig):
    """Configuration for the users application."""
    name = "users"
    verbose_name = "Users"
    
    def ready(self):
        """Called when app is fully loaded."""
        pass

default_app_config = UsersAppConfig
```
