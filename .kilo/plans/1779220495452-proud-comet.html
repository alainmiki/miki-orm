Plan: Django-style Settings, startapp & startproject CLI Commands

Overview

Enhance mikiorm/conf/settings.py with full Django-inspired configuration (DATABASES, INSTALLED_APPS, SECRET_KEY, etc.) and add two new CLI commands: startapp and startproject.

Current State Analysis

Working code to build on

Area File Status
Settings singleton mikiorm/conf/settings.py Has DatabaseConfig, Settings, configure(), connection managers. DATABASES supported; no INSTALLED_APPS
App registration mikiorm/models/register.py Full AppRegistry, AppConfig, register_app(), auto_discover()
CLI entry point mikiorm/cli/cli.py main() with makemigrations, migrate, check, shell, inspectdb, etc.
CLI __main__ mikiorm/cli/__main__.py redirects to cli.main()
Top-level package mikiorm/__init__.py Re-exports configure, settings etc.

Key design constraints

  • File structure uses flat patterns (no settings.py at root level as a django-like project entry yet)
  • App registration already works programmatically via register_app() — needs Django-style declarative INSTALLED_APPS
  • configure() resets connection pools on reconfiguration — preserve this safety
  • Tests exist in test_app_registration.py and test_cli_infrastructure.py — extend rather than rewrite

1.1 AppConfig metadata class (class-level, not an instance)

Add a new AppConfig class inside conf/settings.py that models INSTALLED_APPS entries:

class AppConfig:
    """Metadata for a single app in INSTALLED_APPS."""
    __slots__ = ("name", "path", "label")

    def __init__(self, name: str, path: Optional[str] = None, label: Optional[str] = None):
        self.name = name          # Python import path: e.g. "users"
        self.path = path          # Filesystem path: e.g. "/proj/apps/users"
        self.label = label or name.split(".")[-1]

def configure_from_module(module_path: str) -> None:

    configure(
        databases=getattr(module, "DATABASES", None),
        default_database=getattr(module, "DEFAULT_DATABASE", "default"),

        model_paths=getattr(module, "MODEL_PATHS", None),

2.1 startproject handler (private function)

def _handle_startproject(args):
    name = args.project_name
    target = Path(args.target_dir).resolve()
    project_dir = target / name

    if project_dir.exists():
        print(f"Error: '{project_dir}' already exists.", file=sys.stderr)
        sys.exit(1)

    project_dir.mkdir(parents=True, exist_ok=False)
    settings_dir = project_dir
    settings_file = settings_dir / "settings.py"

    settings_file.write_text(
        generate_settings_template(project_name=name)
    )

    print(f"Created project directory: {project_dir}")
    print(f"  {settings_file.relative_to(Path.cwd())}")

2.2 startapp handler (private function)

def _handle_startapp(args):
    name = args.app_name
    target = args.target_dir

    if target:
        # User specified a folder → create folder/app.py, folder/models.py
        app_dir = Path(target).resolve() / name
        app_dir.mkdir(parents=True, exist_ok=True)
        created_pkg = True
    else:
        # No folder specified → create name/app.py, name/models.py (flat files)
        cwd = Path.cwd()
        app_dir = cwd / name          # not a package unless __init__.py added separately
        app_dir.mkdir(exist_ok=True)
        created_pkg = False

    (app_dir / "app.py").write_text(generate_app_boilerplate(name))
    (app_dir / "models.py").write_text(generate_models_boilerplate(name))

    if created_pkg:
        (app_dir / "__init__.py").touch()

    print(f"Created app '{name}' at: {app_dir}")
    print(f"  app.py")
    print(f"  models.py")

Additional Requirement: Universal Model Registration (No Decorator Needed)

Problem

Today users must annotate every model with @register(app="..."). This is error-prone and unnecessary when INSTALLED_APPS already declares which apps exist and where their models.py files live. The migration engine currently walks model_paths manually rather than using the central AppRegistry, so model discovery and migration are on separate code paths.

Goal

  • Zero decorators required for the common case: once an app is listed in INSTALLED_APPS, calling auto_discover() must find and register every Model subclass in that app’s models.py with the correct app namespace.
  • Single source of truth: MigrationEngine, check, and any other tool must share the same discovery mechanism via AppRegistry.
  • Security hardening: path traversal prevention, module name validation, and whitelist-based import guards in every public entry-point.

D.2 AppRegistry.auto_discover_apps_from_settings()

New public convenience:

def auto_discover_apps_from_settings(self) -> int:
    """Convenience: register and auto-discover every INSTALLED_APPS entry."""
    from ..conf.settings import settings
    count = 0
    for entry in settings.installed_apps:
        label = getattr(entry, "label", entry.name)
        path  = getattr(entry, "path",  None) or _resolve_app_path(entry.name)
        try:
            self.register_app(label, path)
            count += self.auto_discover_app_models(label, verbose=False)
        except Exception as exc:
            logger.warning("Could not auto-register app %r: %s", label, exc)
    return count
  • Private helper _resolve_app_path(name: str) -> str walks sys.path entries, then CWD, to find a matching package directory (first name/__init__.py match wins). Falls back to os.getcwd() so the call never raises.
  • All path inputs are resolved with Path.resolve() (no symlink resolution) and validated with Path.is_relative_to() (Python ≥ 3.9) before use.

E.1 MigrationEngine.discover_models() (line 136–165)

Before: walks settings.model_paths with os.walk, imports each .py file, and relies on @register decorators running at import-time.

After: single source of truth — delegate to AppRegistry.

def discover_models(self) -> None:
    if self._discovered:
        return
    from ..models.register import get_default_registry, auto_discover
    registry = get_default_registry()
    # If settings.installed_apps is configured, register + discover them
    if settings.installed_apps:
        registry.auto_discover_apps_from_settings()
    else:
        # Fallback to legacy model_paths walk
        auto_discover()
    self._discovered = True
  • Calls auto_discover_apps_from_settings() (new D.2) when INSTALLED_APPS is non-empty; falls back to auto_discover() when only model_paths is set.
  • Both paths converge on AppRegistry so MigrationEngine.makemigrations() and MigrationEngine.get_unapplied_migrations() see the same model set.
  • self._discovered guard prevents repeated imports.

F.1 Settings.configure_installed_apps() / configure() extension

Add a dedicated helper called from configure():

def configure_installed_apps(self, apps: list) -> None:
    """Validate and store INSTALLED_APPS entries."""
    validated: list[AppConfig] = []
    for entry in apps:
        if isinstance(entry, str):
            cfg = AppConfig(name=entry)
        elif isinstance(entry, AppConfig):
            cfg = entry
        else:
            raise TypeError(
                f"INSTALLED_APPS entries must be str or AppConfig, got {type(entry)!r}"
            )
        _validate_app_name(cfg.name)            # ← security: identifier / keyword check
        if cfg.path:
            cfg.path = str(Path(cfg.path).resolve())  # ← security: normalise path
            _validate_app_path(cfg.path, cfg.name)    # ← security: traversal guard
        validated.append(cfg)
    self.installed_apps = validated
    # Auto-register with central AppRegistry
    try:
        from ..models.register import get_default_registry
        reg = get_default_registry()
        for cfg in validated:
            if cfg.path and not reg.get_app(cfg.label):
                reg.register_app(cfg.label, cfg.path)
    except Exception as exc:
        logger.warning("Could not auto-register apps: %s", exc)

F.2 Private validators

_RESERVED_KEYWORDS = frozenset({
    "False","None","True","and","as","assert","async","await",
    "break","class","continue","def","del","elif","else","except",
    "finally","for","from","global","if","import","in","is","lambda",
    "nonlocal","not","or","pass","raise","return","try","while",
    "with","yield",
})

def _validate_app_name(name: str) -> None:
    if not name.isidentifier():
        raise ValueError(f"Invalid app name {name!r}: must be a valid Python identifier")
    if name in _RESERVED_KEYWORDS:
        raise ValueError(f"Invalid app name {name!r}: conflicts with a Python keyword")

def _validate_app_path(path: str, app_name: str) -> None:
    """Prevent path traversal — app dir must be inside CWD or a known project root."""
    p = Path(path).resolve()
    cwd = Path.cwd().resolve()
    try:
        p.relative_to(cwd)
    except ValueError:
        # Permit absolute paths outside CWD only if an env-whitelist variable is set
        allowed_root = os.getenv("MIKIORM_ALLOWED_PROJECT_ROOT", "").strip()
        if allowed_root and p == Path(allowed_root).resolve():
            return
        raise ValueError(
            f"App path for {app_name!r} ({p}) is outside the current working directory. "
            "Set MIKIORM_ALLOWED_PROJECT_ROOT to explicitly allow it."
        )

def _validate_module_path(module_path: str) -> None:
    """Prevent importing arbitrary modules as settings."""
    if not module_path:
        raise ValueError("module_path must be a non-empty string")
    parts = module_path.split(".")
    if parts[0] in {"os", "sys", "subprocess", "importlib", "shutil", "code"}:
        raise ValueError(
            f"Refusing to load {module_path!r}: top-level package is disallowed for settings"
        )
    if module_path in {"__main__", "builtins", "builtins"}:
        raise ValueError(f"Refusing to load {module_path!r}: reserved module name")
